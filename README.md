# Climate Change Twitter Analysis

## Project Overview

This project analyses 15M+ tweets about climate change from 2008–2022 to understand how conversations around climate change evolved over time and how people engaged with the topic.

The project demonstrates how a large social media dataset can be cleaned, analysed and turned into meaningful insights without relying on Python.

## Dataset

* **Records:** 15M+ tweets
* **Time period:** 2008–2022
* **Data type:** Social media / Twitter data

## Objectives

The analysis focused on:

* How climate change conversations changed over time
* Patterns in tweet activity and engagement
* Periods of increased public interest
* Trends that could help explain changes in climate-related conversations

## Tools Used

* PostgreSQL
* Power BI

## Analysis

The project involved:

* Data cleaning and preparation
* Handling a large dataset
* Exploratory analysis
* Trend analysis
* Aggregation and filtering
* Visualisation of climate-related Twitter activity

## Key Insights

The analysis identified patterns in climate change conversations and engagement across the 2008–2022 period.
